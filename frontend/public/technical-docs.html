📚 Technisches Glossar

Definitionen aller technischen Begriffe und Konzepte in FavOrg.

Core-Konzepte

CRUD

Create, Read, Update, Delete - Grundlegende Datenbankoperationen für Bookmarks und Kategorien.

Excel-Funktionalität

Drag & Drop System - Bezeichnung für das intuitive Verschieben von Bookmarks zwischen Kategorien, ähnlich Excel-Zellen.

Cross-Level Movement

Ebenenübergreifende Verschiebung - Drag & Drop zwischen verschiedenen Hierarchie-Ebenen der Kategorien.

Lock System

Sperr-System - Schreibschutz für wichtige Bookmarks, verhindert versehentliches Löschen oder Bearbeiten.

Status-Terminologie

Dead Links

Tote Links - URLs die HTTP 404, 500 oder DNS-Fehler zurückgeben.

Timeout Links

Zeitüberschreitung - URLs die zu lange zum Laden brauchen (>30s).

Localhost Links

Lokale URLs - Entwicklungs-URLs (127.0.0.1, localhost) die separat behandelt werden.

Duplicate Detection

Duplikat-Erkennung - URL-Normalisierung zur Identifikation identischer Links.

Frontend-Terminologie

Toast System

Meldungen-System - Temporäre Benachrichtigungen mit sonner Library. "Meldungen Delay" = permanente Anzeige mit X-Button.

Responsive Breakpoints

Bildschirm-Anpassung - Desktop (>1200px), Tablet (768-1200px), Mobile (<768px).

Dark Theme

Dunkles Design - CSS-Variablen basiertes Theme-System mit --bg-primary: #1a1f2e.

Backend-Terminologie

Upsert Logic

Update oder Insert - Kategorien werden aktualisiert falls vorhanden, sonst neu erstellt.

URL Normalization

URL-Normalisierung - Entfernung von Trailing Slashes, Query Parameters für Duplikat-Erkennung.

Async Validation

Asynchrone Validierung - Parallele Link-Prüfung mit aiohttp für bessere Performance.

🔌 API-Dokumentation

Vollständige REST API Endpunkt-Referenz für FavOrg Backend.

Bookmark Endpoints

GET /api/bookmarks
Beschreibung: Alle Bookmarks abrufen, optional mit Status-Filter
Query Params: status_type (optional), category (optional)
POST /api/bookmarks
Beschreibung: Neuen Bookmark erstellen
Body: JSON mit title, url, category, description, is_locked
PUT /api/bookmarks/{id}
Beschreibung: Bookmark aktualisieren
Body: JSON mit zu ändernden Feldern
DELETE /api/bookmarks/{id}
Beschreibung: Bookmark löschen (außer gesperrt)
Response: HTTP 403 wenn gesperrt

Specialized Bookmark Operations

POST /api/bookmarks/validate
Beschreibung: Alle Links auf Erreichbarkeit prüfen
Response: {total_checked, dead_links_found, message}
DELETE /api/bookmarks/dead-links
Beschreibung: Alle toten Links löschen (localhost verschont)
Response: {removed_count, message}
POST /api/bookmarks/find-duplicates
Beschreibung: Duplikate finden und markieren
Response: {duplicate_groups, marked_count, message}
DELETE /api/bookmarks/duplicates
Beschreibung: Alle als duplicate markierten Links löschen
Response: {removed_count, message}

Category Management

GET /api/categories
Beschreibung: Alle Kategorien mit Bookmark-Anzahl
Response: Array mit {id, name, parent_category, bookmark_count}
POST /api/categories
Beschreibung: Neue Kategorie erstellen
Body: {name, parent_category}
PUT /api/categories/{id}
Beschreibung: Kategorie umbenennen
Body: {name}
DELETE /api/categories/{id}
Beschreibung: Kategorie löschen, Bookmarks zu "Uncategorized"
Response: Anzahl verschobener Bookmarks

Export & Import

POST /api/export
Beschreibung: Bookmarks exportieren
Body: {format: "xml|csv|html|json", category?: string}
Headers: Content-Type je nach Format, attachment filename
POST /api/import
Beschreibung: Bookmark-Datei importieren
Body: Multipart file upload
Formats: HTML, XML, CSV, JSON

Statistics & System

GET /api/statistics
Beschreibung: System-Statistiken abrufen
Response: {total_bookmarks, active_links, dead_links, locked_links, localhost_links, duplicate_links, unchecked_links, total_categories}
POST /api/bookmarks/create-comprehensive-test-data
Beschreibung: 100 realistische Testdaten erstellen
Response: {message, created_count, categories_created, details}

📊 Status-System

Umfassendes Status-Management mit 7 verschiedenen Bookmark-Zuständen.

Status-Typen Übersicht

Status Wert Icon Beschreibung Automatische Erkennung
Aktiv active ✅ Funktionierende, erreichbare URLs HTTP 200-299 Response
Tote Links dead 💀 Nicht erreichbare URLs HTTP 404, 500, DNS-Fehler
Gesperrt locked 🔒 Schreibgeschützte Bookmarks Manuell gesetzt
Timeout timeout ⏱️ Zu langsame Verbindungen Verbindung >30s
Localhost localhost 🏠 Lokale Entwicklungs-URLs 127.0.0.1, localhost Pattern
Duplikate duplicate 📋 Mehrfach vorhandene URLs URL-Normalisierung Matching
Ungeprüft unchecked ❓ Noch nicht validierte Bookmarks Standard bei Import

Status-Übergänge

// Automatische Status-Übergänge bei Validierung: unchecked → active (HTTP 200-299) unchecked → dead (HTTP 404, 500, DNS-Fehler) unchecked → timeout (Verbindung >30s) unchecked → localhost (localhost/127.0.0.1 Pattern) // Manuelle Status-Änderungen: any_status → locked (Sperr-Button) locked → active (Entsperr-Button) any_status → duplicate (Find-Duplicates Funktion) // Bulk-Aktionen: dead → deleted (TOTE Links Button) duplicate → deleted (Duplikate Button) localhost → deleted (Localhost Button)

Database-Schema Status-Felder

Datenbank-Operationen

Bookmark Queries
# Alle aktiven Bookmarks db.bookmarks.find({"status_type": "active"}) # Bookmarks einer Kategorie db.bookmarks.find({"category": "Development"}) # Gesperrte Bookmarks db.bookmarks.find({"is_locked": true}) # Text-Suche in mehreren Feldern db.bookmarks.find({ "$or": [ {"title": {"$regex": "github", "$options": "i"}}, {"url": {"$regex": "github", "$options": "i"}}, {"description": {"$regex": "github", "$options": "i"}} ] })
Aggregation Pipelines
# Kategorie-Statistiken db.bookmarks.aggregate([ {"$group": { "_id": "$category", "count": {"$sum": 1}, "active": {"$sum": {"$cond": [{"$eq": ["$status_type", "active"]}, 1, 0]}}, "dead": {"$sum": {"$cond": [{"$eq": ["$status_type", "dead"]}, 1, 0]}} }} ]) # Duplikat-Erkennung db.bookmarks.aggregate([ {"$group": { "_id": "$url", "count": {"$sum": 1}, "bookmarks": {"$push": "$$ROOT"} }}, {"$match": {"count": {"$gt": 1}}} ])

Index-Strategien

// Empfohlene Indexes für Performance: // 1. Unique Index auf FavOrg ID db.bookmarks.createIndex({"id": 1}, {"unique": true}); db.categories.createIndex({"id": 1}, {"unique": true}); // 2. Compound Index für Category + Status Queries db.bookmarks.createIndex({"category": 1, "status_type": 1}); // 3. Text Index für Search Functionality db.bookmarks.createIndex({ "title": "text", "url": "text", "description": "text" }); // 4. Index für URL-basierte Duplikat-Erkennung db.bookmarks.createIndex({"url": 1}); // 5. Index für Timestamp-basierte Queries db.bookmarks.createIndex({"created_at": -1}); db.bookmarks.createIndex({"last_checked": -1});
